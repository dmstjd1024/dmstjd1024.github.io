Backend Roadmap

백엔드 개발자의 다섯 막

막을 가르는 건 아는 기술의 개수가 아니라 책임지는 범위다. 코드 품질은 시니어에서 상한에 닿고, 그 위는 설계 판단과 범위로 올라간다.

1 다음에 집중할 순서

  1. 1막

    기초

    범위 · 태스크

    • 언어 문법 · 자료구조
    • SQL · HTTP
    • Git · Linux

    기능 하나를 혼자 끝까지 낸다

  2. 2막

    주니어

    범위 · 기능

    • Spring · JPA · REST
    • 테스트 · 코드 리뷰
    • 인증 · 인가
    • CI/CD 기초

    운영 서비스를 맡아 장애를 직접 받는다

  3. 3막 지금 여기

    미들

    범위 · 서비스

    • 캐시 · 선착순 트래픽
    • 메시지 큐 (Kafka)
    • Docker · 클라우드
    • 모니터링 · 알림
    • 인덱스 기초

    실패 모드를 설계하고, 결정을 글로 설명한다

  4. 4막 다음

    시니어

    범위 · 팀 도메인

    • 1분산 정합성 — Outbox · 멱등 소비 · 보상 트랜잭션
    • 2부하 테스트 · 프로파일링 (k6)
    • 3실행계획 · 인덱스 튜닝
    • 4분산 추적 · SLO (OpenTelemetry)
    • 무중단 · 점진 마이그레이션
    • ADR · 설계 문서

    여러 팀, 여러 해의 방향을 맡는다

  5. 5막

    스태프

    범위 · 여러 팀 · 여러 해

    • 기술 전략 · 로드맵
    • build vs buy 판단
    • 플랫폼 · 공통 라이브러리
    • 복잡한 설계를 단순한 기반으로

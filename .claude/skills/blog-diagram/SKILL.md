# 블로그 도식

이 블로그의 도식은 **인라인 SVG + `dg-*` 클래스**다. 색을 파일에 박지 않고
`_sass/diagram.scss` 가 테마 토큰(`--fg`, `--accent`, `--border`)으로 칠한다.
그래서 다크모드 토글에 본문과 같이 반응한다.

## 두 가지 필수 조건

이 둘 중 하나만 빠져도 도식이 깨진다. 먼저 확인한다.

1. **`.diagram` 으로 감싼다.** `_sass/diagram.scss` 의 색 규칙이 전부
   `.diagram` 하위 선택자다. `{% include %}` 만 쓰면 스타일이 안 붙어
   검은 도형이 된다.

   ```liquid
   <div class="diagram">
   {% include diagrams/이름.svg %}
   </div>
   ```

2. **SVG 안에 색을 쓰지 않는다.** `fill="#fff"`, `stroke="#333"` 를 쓰면
   다크모드에서 그대로 남는다. 아래 클래스만 쓴다.

## 클래스

권위 있는 정의는 `_sass/diagram.scss` 다. 새 클래스가 필요하면 거기에 추가한다.

| 클래스 | 쓰임 |
|---|---|
| `dg-item` | 기본 노드 상자 |
| `dg-hl` | 강조 노드 (강조색 테두리 + 옅은 채움) |
| `dg-zone` | 묶음 영역 |
| `dg-zone-a` | 강조 묶음 (점선 + 강조색) |
| `dg-t` | 노드 제목 |
| `dg-s` | 부제·보조 텍스트 |
| `dg-m` | 본문급 텍스트 |
| `dg-n` | 강조색 텍스트 (`dg-hl` / `dg-zone-a` 안에서 씀) |
| `dg-arw` | 연결선 |
| `dg-arw-a` | 강조 연결선 |
| `dg-mask` | 선 위에 얹는 라벨의 배경 |

화살촉은 `<marker>` 안 `<path>` 에 클래스를 주지 않으면
`marker path { fill: var(--border-strong) }` 가 적용된다.

## 구조 — 존과 연결선

**묶음(존)으로 나누고 존 사이를 화살표로 잇는다.** 상자를 쌓고 글자만 넣으면
모서리 둥근 표지 도식이 아니다. 관계가 그림에 있어야 한다.

- 존 라벨은 존 테두리 위에 얹고 `dg-mask` 로 선을 가린다.
- 강조는 **한 곳만**. 여러 곳을 강조하면 강조가 사라진다.

### 존 안에서는 화살표를 아껴 쓴다

**순서가 실제로 있을 때만 잇는다.** 선택지끼리 화살표로 이으면
`PostgreSQL → MySQL` 처럼 **없는 순서를 만들어낸다.**
대안·병렬 항목은 나란히 놓기만 한다.

## 좌표는 스크립트로 만든다

도식이 여러 개면 손으로 좌표를 찍지 않는다. 여백과 노드 높이가 미세하게
어긋난다. `gen.py` 의 `build()` 가 존·노드 목록을 받아 좌표를 계산하고,
글자 수로 노드 폭을 잡아 폭이 넘치면 다음 줄로 접는다.

실제 사용례는 `example-build.py` — 로드맵 글의 도식 7개를 만든 스크립트다.
그대로 실행하면 `_includes/diagrams/` 의 해당 파일들이 재생성된다.

한 장짜리 특수 배치(분기, 두 줄로 꺾이는 흐름)는 손으로 쓰는 편이 낫다.
`backend-roadmap--stages.svg`, `backend-roadmap--containers.svg` 가 그 예다.

## Mermaid 를 쓸 때

Mermaid 도 살아 있다. 프론트매터에 `mermaid: true` 를 넣으면
`_layouts/page.html` 이 CDN 에서 불러와 렌더한다.

| 상황 | 도구 |
|---|---|
| 시퀀스·상태도·ER, 자동 배치로 논지가 안 깨짐 | Mermaid |
| 존으로 묶어야 함, 강조가 필요함, 노드가 10개 넘는 선형 흐름 | 인라인 SVG |

⚠️ **긴 선형 흐름을 Mermaid 로 그리지 않는다** (실측 2026-08-22).
노드 16개를 `flowchart LR` 로 그리면 2543px 한 줄로 펴지고, 본문 폭(52rem)에
맞춰 축소되면서 글자가 읽히지 않는다. subgraph 를 화살표로 이으면 dagre 가
내부 `direction` 을 무시하고 전부 세로로 세운다. 보이지 않는 링크(`~~~`)로
쌓아야 가로줄이 유지되고, elk 레이아웃도 결과는 같다.

## 확인

도식은 빌드만으로 검증되지 않는다. **라이트/다크 양쪽을 눈으로 본다.**

```bash
bundle exec jekyll serve --port 4000 --livereload
```

다크모드는 `localStorage.setItem('theme','dark')` 로 켠다
(`body.dark-theme` 클래스로 동작하므로 OS 설정과는 별개다).

- 노드 채움이 페이지 배경을 따라가는가 (라이트 흰색 / 다크 `#0d1117`)
- 도식이 축소돼 글자가 뭉개지지 않았는가
- 좁은 창에서 본문을 밀어내지 않고 도식만 가로 스크롤되는가

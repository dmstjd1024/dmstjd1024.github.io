## 한 줄로

Jekyll 블로그의 교차 검토를 회차가 결함 없이 끝날 때까지 돌렸고, 29회차가 최종 커밋 `a1f7bf0`에서 "손볼 곳 없음"을 냈다. 수정 중에는 날짜 기본값을 지운 부작용으로 RSS 50건 중 32건이 빈 "Index" 항목이 된 일도 있었다. 자동 검사는 통과했지만 실제 휴대폰과 VoiceOver·TalkBack은 확인하지 못했다.

## 교차 검토와 종료 기준

교차 검토는 결과물을 만든 쪽이 아닌 다른 검토자에게 결함을 찾게 하는 방식이다. 이번에 정한 종료 기준은 하나다.

- 검토 회차가 결함 없이 끝나야 "없습니다"로 답한다.

회차별 배포 커밋은 다음과 같이 이어졌다.

`c2c4f46` → `fe70774` → `8a3c63e` → `2fb15d4` → `660ba6f` → `5c33b28` → … → `a1f7bf0`

## 실제로 고친 것

### 사이트맵과 RSS의 날짜

사이트맵의 날짜는 검색엔진에 페이지가 언제 바뀌었는지 알려 주는 값이다. 그런데 목록 페이지 약 30개의 날짜가 2025-05-27에 고정돼 있었다. `category_lastmod.rb`를 두어 카테고리 최신 글 날짜를 쓰도록 했다.

RSS `posts.xml`에서는 날짜 기본값을 지운 부작용이 나왔다. 피드 50건 중 32건이 빈 "Index" 항목이 됐다. 목록 페이지에 날짜를 채우고, 이 페이지들을 피드에서 제외해 해결했다.

### `<wbr>` 두 건

`<wbr>`은 줄을 바꿔도 되는 지점을 브라우저에 알려 주는 태그이고, 닫는 태그를 쓰지 않는 요소다. 여기서 문제가 두 가지 나왔다.

- **닫는 태그**: jekyll-loading-lazy가 `</wbr>`를 붙였다. `_plugins/wbr_close_tag.rb`로 이를 제거한다.
- **화면 낭독기**: 화면 낭독기가 이름 사이에 공백을 넣어 읽었다. `<wbr aria-hidden="true">`로 고쳤다.

### 표 안 코드와 `og:title`

- **표 안 코드**: 글자 단위로 끊지 않고 표만 가로 스크롤한다.
- **카테고리 페이지 `og:title`**: 사이트 이름 중복을 제거했다.

### 자동 발행이 지운 코드 펜스

`cron-job/blog-autopost/autopost.py`는 AI 응답을 벗기면서 본문 안의 코드 블록 울타리(백틱 세 개)까지 지우고 있었다. 해당 줄을 제거하고, 영향을 받은 글 2편의 펜스도 복구했다.

## 최종 검증

- 이전·다음 글 176/176 정상

- 포커스 테두리가 안 보이는 경우 0건(22,752곳 확인)

## 한 줄로

한국투자증권(KIS) 모의투자 앱키로 토큰은 정상 발급됐다. 그런데 계좌 조회는 `모의투자 처리계좌의 ID와 사용자정보가 상이하여 처리 불가능 합니다.` 오류로 막혔다. 원인 후보 두 개를 좁혀 두었고, 주말에는 모의 주문을 받지 않아 실측은 10/12(월) 장중으로 미뤘다.

## 배경: 자동매매 v2 의 사람 태스크 0007

자동매매 v2 프로젝트의 M1 코드는 19개 태스크 중 9개(47%)를 끝냈다. M0~M10 전체로 보면 20%다. 그다음 태스크가 0007(KIS 모의 실측)인데, 에이전트가 아니라 사람이 직접 해야 하는 태스크라 여기서 진행이 멈췄다.

0007 에서는 프로브(동작 확인용 스크립트)를 돌린다. 프로브는 모의 계좌에 지정가 주문을 넣었다가 취소한다. 그래서 다음 세 가지가 모두 갖춰져야 한다.

- 모의투자용 앱키·시크릿
- 그 앱키에 연결된 모의 계좌번호
- 모의 주문을 받는 시간대

이날은 세 가지가 모두 걸렸다.

## 첫 번째 벽: 비밀 파일에 값이 한 줄뿐이었다

`kis-paper.env` 에는 `KIS_IS_PAPER` 한 줄만 있었다. 원래는 1Password CLI(`op`)로 키를 읽어 이 파일을 채워야 하는데, `op` 가 응답하지 않았다.

고치는 방법은 두 가지였다.

- 1Password 앱을 `Cmd+Q` 로 완전히 종료한 뒤 다시 켠다
- 키를 직접 넣는다

이날은 키를 직접 받아서 진행했다.

## 두 번째 벽: 토큰은 되는데 계좌가 안 맞는다

토큰 발급은 성공했다. 그러니 앱키와 시크릿 값 자체에는 문제가 없다. 막힌 곳은 계좌였다. 계좌번호를 두 개 넣어 봤다.

| 넣은 계좌 | 결과 | 의미 |
|---|---|---|
| `5021****` | `INVALID_CHECK_ACNO` | 홈페이지 모의투자 대회 계좌라 API 앱키와 연결돼 있지 않다 |
| `1245****-01` | `모의투자 처리계좌의 ID와 사용자정보가 상이하여 처리 불가능 합니다.` | 계좌는 존재하지만 사용자 정보와 맞지 않는다 |

(계좌번호는 이 글에서 가렸다.)

두 오류는 성격이 다르다. 첫 번째는 계좌번호 검증에서 바로 걸렸다. 홈페이지 모의투자 대회 계좌와 API 앱키에 연결된 모의 계좌는 서로 다른 계좌다. 두 번째는 계좌가 있다는 데까지는 통과했고, 그 계좌와 요청한 사용자 정보가 맞지 않는다는 오류다.

### 신청 화면에서 확인한 것

브라우저용 Claude 로 KIS Developers 신청 화면을 열어 봤다.

- 앱에 연결된 모의 계좌는 두 번째로 넣은 `1245****` 가 맞았다
- 신청일은 2026.10.10, 만료일은 2027.10.10 이다
- 다만 모의투자는 투자기간이 3개월 이내라 갱신되지 않는다

비밀 파일의 계좌 줄은 `1245****-01` 형식으로 넣어 두었다. 계좌는 맞게 넣었는데 여전히 "ID와 사용자정보가 상이" 오류가 난다는 뜻이다.

### 남은 원인 후보

1. **앱키가 이 계좌에 연결된 키가 아니다.** 신청 화면에서 APP Key 의 "복사" 버튼을 눌러 앞 6자리를 대조해 봐야 한다.
2. **오늘(토요일) 신청해서 아직 반영되지 않았다.** 이건 확실하지 않다.

## 세 번째 벽: 주말에는 모의 주문도 받지 않는다

계좌 문제가 풀려도 이날은 프로브를 끝까지 돌릴 수 없었다. 프로브는 지정가 주문을 넣었다가 취소하는데, 주말에는 모의 주문도 받지 않는다.

그래서 0007 은 **10/12(월) 장중 09:00~15:30** 에 하기로 정했다. HTS/MTS 에서 넣는 대조 주문 1건도 그때 같이 한다. 앱키 앞 6자리 대조도 확인할 항목으로 남았다.

마지막에 "`op` 에 모의투자용(imitation) key·secret 값이 있다"는 이야기가 나왔지만, 이 건은 결론 없이 끝났다.

## 실수 하나: 비밀값이 대화 기록에 남았다

`op` 가 막혀서 키를 직접 넣는 과정에서 모의 앱키·시크릿을 대화창에 평문으로 붙여넣었다. 그 값은 대화 기록 export 에 그대로 남았고, 비밀값 필터에도 걸리지 않았다. 모의투자 키라도 평문으로 남은 이상 노출된 것으로 보고 처리해야 한다.

## 정리

- 토큰 발급이 성공해도 계좌 연결까지 맞았다는 뜻은 아니다. 토큰으로 확인되는 것은 앱키·시크릿 값이 정상이라는 것까지다.
- 홈페이지 모의투자 대회 계좌는 API 에서 `INVALID_CHECK_ACNO` 로 거부된다. 앱에 연결된 모의 계좌는 KIS Developers 신청 화면에서 확인한다.
- 계좌가 맞는데도 `ID와 사용자정보가 상이` 가 나오면, 다음 확인 대상은 앱키와 계좌의 짝이다.
- 주문까지 확인하는 프로브는 평일 장중에만 끝까지 돌릴 수 있다.

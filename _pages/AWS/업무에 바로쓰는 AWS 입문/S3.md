## S3 란

- 매우 안전하고 가변적인 오브젝트 저장 공간 제공
- 버킷 : 최상의 폴더

## S3 오브젝트 구성 요소 이해
- Key Value 구조 (key : 오브젝트 파일명, value : 오브젝트 내용물)
- 같은 키로 다시 업로드하면 덮어쓰며, 버저닝을 켜둔 버킷에서는 이전 버전도 보존

## S3 데이터 일관성 모델
- 데이터 일관성 모델 : 데이터를 쓴 뒤 조회할 때 어떤 상태가 보이는지에 대한 보장

</div>
 
### 객체 생성·덮어쓰기·삭제는 강한 일관성
- PUT으로 새 객체를 만들거나 덮어쓰고, DELETE로 삭제한 뒤 성공 응답을 받으면 GET/LIST에 바로 반영
- 2020년 12월부터 모든 리전에서 제공

### 버킷 설정 변경은 별도로 본다
- 버킷 삭제 후 버킷 목록 조회나 버저닝 최초 활성화 같은 설정 변경에는 최종 일관성이 적용
- 객체의 PUT·DELETE 일관성과 구분해야 함

## S3 오브젝트의 스토리지 클래스

아래는 버킷 종류가 아니라 오브젝트별 저장 등급이다. [AWS 스토리지 클래스 문서](https://docs.aws.amazon.com/AmazonS3/latest/userguide/storage-class-intro.html)를 기준으로 구분한다.

<div class="diagram" role="img" aria-label="S3 스토리지 유형 비교">
{% include diagrams/s3--storage-class.svg %}
</div>

- **S3 Standard**
    - 여러 가용영역에 데이터를 중복 저장하는 기본 등급이다.
- **S3 Standard-IA(드문 접근)**
  - 신속한 접근이 요구될 때 뛰어난 성능 발휘 (재해복구, 백업파일 보관)
- **S3 One Zone-IA**
  - 하나의 가용영역에 저장. 해당 영역의 물리적 손실에는 데이터를 잃을 수 있어 재생성 가능한 사본에 적합
- **S3 Glacier 계열**
  - 몇년에 한번 사용할까 말까 할 때 사용
  - Instant Retrieval은 즉시 조회, Flexible Retrieval·Deep Archive는 복원 필요. 복원 시간은 등급·요청 옵션별로 다름
- **S3 Intelligent-Tiering**
  - 오브젝트 접근 주기 에 따라 자동으로 스토리지 티어를 변경

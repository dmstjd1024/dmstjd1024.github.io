## S3 란

- 매우 안전하고 가변적인 오브젝트 저장 공간 제공
- 버킷 : 최상의 폴더

## S3 오브젝트 구성 요소 이해
- Key Value 구조 (key : 오브젝트 파일명, value : 오브젝트 내용물)
- 업로드된 파일에 다른 내용이 들어가있따면, 버전 2로 업로드 가능

## S3 데이터 일관성 모델
- 데이터 일관성 모델 : S3 버킷에 오브젝트 새로 업로드 또는 변경 시, 짧은 지연 존재때문에 생기는 현상

### 쓰기 일관성 후 읽기 모델
- PUT API를 사용해서 업데이트 -> 지연없이 바로 사용 가능
- '강한 일관성 모델' 이라 부름

### 최종 일관성 모델
- UPDATE, DELETE API 사용 시, 결과가 바로 반영되지 않음
- 한 지역에 여러개 노드가 연결되어 있어, 모든 노드에 적용되지 않았을 때 이전 결과를 얻을 수 있음

## S3 버킷 다양한 스토리지 유형

<div class="diagram" role="img" aria-label="S3 스토리지 유형 비교">
{% include diagrams/s3--storage-class.svg %}
</div>

- **일반 S3 버킷**
    - 데이터 손실 100% 가까이 막아준다.
- **S3 드문 접근 버킷** 
  - 신속한 접근이 요구될 때 뛰어난 성능 발휘 (재해복구, 백업파일 보관)
- **S3 단일 존 버킷**
  - 하나의 가용영역에만 의존, 가용 영역 다운 시, 오브젝트 접근 불가
- **글레시어(빙하) 버킷**
  - 몇년에 한번 사용할까 말까 할 때 사용
  - 걸리는 시간 4 ~ 5시간
- **지능적 티어링 버킷**
  - 오브젝트 접근 주기 에 따라 자동으로 스토리지 티어를 변경
